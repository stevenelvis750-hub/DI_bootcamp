# 📝 Task Manager App

## 🚀 Overview
A simple React Task Manager application built with:
- **useContext** for global state management
- **useReducer** for handling task actions
- **useRef** for inline task editing

Features:
- Add new tasks
- Toggle tasks as completed/active
- Edit tasks inline
- Filter tasks (All, Completed, Active)
