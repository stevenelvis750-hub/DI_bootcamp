# React XP

One React app used for all the Exercises XP. Use the buttons at the top to switch between exercises.

## Exercises

- **Clock**: class component clock in compass format (`Clock.js`, `Clock.css`)
- **Error 1 / 2 / 3**: error boundary simulations (`App.js`, `ErrorBoundary.js`)
- **Lifecycle**: updating and unmounting methods (`Color.js`)
- **Form**: form container with values shown live and sent in the URL (`App.js`, `FormComponent.js`)

## Run it

    npm install
    npm start

Opens at http://localhost:3000.
